# ToasterOS3-AppStore
offical app store for toaster os

How to add your own apps. to make your own apps you need todo the following.  
1. add your Name on frist line of file under `ProgramFiles/<Program Name>/ProgramData`  
2. then after you've done that make a folder called `files` and put all of your app files into there  
3. add your own file listing all files needing under `ProgramFiles/<Program Name>/FilesToInstall` then list the relative path to all the files your app.
4. now add your verson folder under `ProgramFiles/<Program Name>/verson` everytime you change the files for your app change the text on here and it will push a update to everyone.  
5. once your ready to publish add your program dictionary into the Programs.txt file.
